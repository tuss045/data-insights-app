# 📊 Data → Insights | AI Workflow Tool

A free, browser-based tool that converts raw business data into actionable insights using AI. No backend, no server, no cost to host.

![Data Insights Tool](https://img.shields.io/badge/AI-Powered-blue) ![Free](https://img.shields.io/badge/Hosting-Free-green) ![No Backend](https://img.shields.io/badge/Backend-None-orange)

## ✨ Features

- **Paste any data** — CSV, tabular text, key-value pairs
- **AI analysis** — trends, anomalies, KPIs, risks, opportunities
- **Instant results** — KPI cards, narrative summary, action recommendations
- **100% free** — powered by Groq's free API tier
- **Works on mobile** — fully responsive design
- **Dark mode** — auto-detects system preference

## 🛠️ Setup

### 1. Get a free Groq API key
- Go to [console.groq.com](https://console.groq.com)
- Sign up free (no credit card needed)
- Click **API Keys** → **Create API Key**
- Copy your key (starts with `gsk_`)

### 2. Use the app
- Open the live link above
- Paste your Groq API key in the yellow box (saved in your browser only)
- Paste your data or use a sample dataset
- Select analysis focus areas
- Click **Generate insights**

## 🔒 Privacy & Security

- Your API key is stored **only in your browser** (localStorage)
- Your data is sent directly to Groq's API — nothing is stored anywhere
- No tracking, no analytics, no server
